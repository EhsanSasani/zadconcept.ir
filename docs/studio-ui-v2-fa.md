# رابط استودیو — نسخه دوم

این پچ روی نسخهٔ قبلی Studio Operations و همان شاخهٔ محلی
`feature/studio-operations` اعمال می‌شود. پچ دادهٔ نمایشی می‌تواند قبلاً اعمال شده باشد؛
کد seed در این پچ تغییر نکرده است.

## تغییرات

- ظاهر هماهنگ با رنگ‌های زاد، تایپوگرافی خواناتر، کارت‌های آماری و نمایش نتیجهٔ تولید.
- کنترل‌های لمسی، منوی پایین موبایل، منوی کشویی با پشتیبانی صفحه‌کلید، حرکت‌های کوتاه
  و رعایت تنظیم کاهش حرکت سیستم.
- سورت افزایشی/کاهشی با کلیک روی عنوان ستون‌ها؛ جهت فعلی با فلش و `aria-sort` مشخص است.
  محصولات قبل از صفحه‌بندی و روی تمام نتایج فیلترشده مرتب می‌شوند.
  سورت و صفحه‌بندی بدون بارگذاری مجدد کل صفحه انجام می‌شوند؛ لینک‌ها بدون JavaScript هم کار می‌کنند.
- حفظ ترتیب و فیلترها در صفحه‌بندی و تغییر بازه؛ جستجو و بازنشانی فیلترها.
- نمودار روند با انتخاب سری، مقدار هر روز و جدول قابل مرتب‌سازی؛ نمودار ترکیب تولید
  و نوارهای نتیجه از داده‌های واقعی همان بازه استفاده می‌کنند.
- نمایش بزرگ عکس محصول، تأیید تغییر وضعیت و حالت «در حال ذخیره» برای فرم‌ها.
- عکس اختیاری فلوریست در فرم افزودن/ویرایش، پیش‌نمایش زنده، نمایش در فهرست، پروفایل،
  کارت‌های داشبورد و جدول محصولات؛ بدون عکس، حرف اول نام نمایش داده می‌شود.
- عکس فلوریست از مسیر پردازش تصویر موجود پروژه عبور می‌کند: اعتبارسنجی تصویر،
  حداکثر فایل ۲۰ مگابایت، اصلاح جهت عکس و خروجی WebP با ضلع بزرگ حداکثر ۸۰۰ پیکسل.
  هنگام ویرایش می‌توان عکس را نگه داشت، جایگزین کرد یا از پروفایل برداشت.

## اعمال در Windows / PowerShell

سرور توسعه را متوقف کنید. پچ را در ریشهٔ پروژه بگذارید و ابتدا بررسی کنید:

```powershell
git branch --show-current
git status --short
git apply --check .\zad-studio-ui-v2.patch
```

اگر بررسی پچ بدون خطا بود:

```powershell
git apply .\zad-studio-ui-v2.patch
python manage.py migrate
python manage.py check
python manage.py runserver
```

صفحهٔ `/studio/` را با `Ctrl+F5` تازه کنید. برای عکس از «فلوریست‌ها ← افزودن فلوریست»
یا «پروفایل فلوریست ← ویرایش» استفاده کنید.

مهاجرت `0036_florist_profile_photo` فقط ستون اختیاری عکس را به مدل Florist اضافه می‌کند؛
فلوریست‌ها و محصولات موجود حفظ می‌شوند. عکس‌ها در `MEDIA_ROOT/studio/florists/` قرار می‌گیرند.
در انتشار بعدی VPS، migrate و collectstatic معمول پروژه لازم‌اند و رسانه‌ها باید طبق
روال موجود حفظ و سرو شوند. این پچ خودش چیزی را روی VPS منتشر نمی‌کند.

پس از بررسی محلی، فایل دانلودی پچ را حذف و تغییرات کد را روی همین شاخه commit کنید.

## بررسی انجام‌شده

- کل مجموعه Django: ۴۱۹ تست، بدون شکست، یک تست skipped.
- تست‌های Worker تلگرام: ۱۸ تست موفق.
- `check`، `makemigrations --check --dry-run` و بررسی فاصله‌های Git بدون خطا.
- اجرای migration در دیتابیس آزمایشی محلی و تست عکس معتبر/نامعتبر، مجوز ثبت،
  نگه‌داشتن/حذف عکس در ویرایش و سورت کل داده‌ها پیش از صفحه‌بندی.
- مرورگر Chromium در عرض‌های ۱۴۴۰، ۷۶۸، ۳۹۰ و ۳۷۵ پیکسل؛ بدون سرریز افقی کل صفحه
  در صفحات بررسی‌شده. جدول‌های پهن در قاب خود به طرفین حرکت می‌کنند.
- کلیک سورت، صفحه‌بندی، حفظ سورت پس از تغییر بازه، جدول دادهٔ نمودار، نمایش عکس،
  لغو تأیید تغییر وضعیت، منوی موبایل و آپلود واقعی عکس تا نمایش در پروفایل بررسی شدند.

بازبینی موبایل با اندازهٔ نمایشگر شبیه‌سازی‌شده در Chromium انجام شده است؛
روی دستگاه واقعی iPhone یا Safari آزمایش نشده است.
