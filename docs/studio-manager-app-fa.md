# بازطراحی یکپارچه پنل مدیر زاد

## مبنا و محدوده
این اصلاحیه روی zad-studio-manager-mobile.patch اعمال می‌شود؛ ابتدا باید پچ قبلی روی لوکال وجود داشته باشد. این فایل جایگزین پچ قبلی نیست.
هدف: ناوبری ثابت و قابل پیش‌بینی، خوانایی موبایل، خلاصه فشرده، نمایش تدریجی اطلاعات و دسترسی سریع به جزئیات.

### صفحه‌ها
- خانه: ارزش فروش برجسته، موجودی فعلی، چهار شاخص فرعی، هشدار ثبت ناقص در صورت وجود، چهار محصول ویترین و عملکرد تیم.
- محصولات: خلاصه کوچک، جست‌وجوی در دسترس، فیلترهای پیشرفته بازشدنی. جدول دسکتاپ روی گوشی به کارت تبدیل می‌شود؛ فرم عملیاتی و شناسه‌ها تکثیر نمی‌شوند. زمان‌ها و نوع تولید از طریق جزئیات محصول در دسترس هستند.
- جزئیات محصول: عکس قابل بزرگ‌نمایی، قیمت، سازنده، نوع تولید، منبع، ثبت‌کننده در صورت وجود، یادداشت، زمان‌های ثبت‌شده و آخرین پیگیری‌های تلگرام. نمایش ویرایش مطابق مجوز و محدودیت فعلی است. این صفحه تاریخچه ویرایش اختراعی یا قابلیت لغو فروش جدید ندارد.
- تحلیل‌ها: شاخص‌ها، نمودار رویدادها، ترکیب تولید بازشدنی و مقایسه نوع محصول. درصدهای گمراه‌کننده بین جمعیت‌های متفاوت از بخش نتیجه حذف شده‌اند.
- تیم و پروفایل: کارت‌های خوانا، عملکرد منظم و نرخ نامشخص «—» وقتی تولیدی برای محاسبه وجود ندارد. بازه انتخابی در ورود از خانه/فهرست به پروفایل حفظ می‌شود.
- بیشتر: دسترسی به حساب‌ها، پیگیری تلگرام، ثبت محصول و وضعیت داده‌ها. راهنمای کپشن اطلاعات فرعی و بازشدنی است.
- حساب‌ها: فرم ساخت حساب جمع‌شده است؛ در خطا باز می‌ماند. غیرفعال‌کردن ورود تأیید نام‌دار دارد؛ مجوزها و محافظت حساب مدیریتی حفظ شده‌اند.
- پیگیری تلگرام: مقصد سفارشی/روزانه مشخص، نام اقدام روشن، زمان خروج برنامه‌ریزی‌شده قابل مشاهده و نتیجه حفظ پیام سفارشی توضیح داده شده است.
- گزارش هر شاخص: نمودار روزانه با جدول جایگزین و مقایسه فلوریست‌ها. صفحه موجودی ویترین تصویری و مرتب‌سازی دارد.
- فرم‌های ثبت و ویرایش: ورودی‌های خوانا، اندازه لمس مناسب، خطا و پیش‌نمایش مطابق الگوی مشترک.

## قواعد حفظ‌شده
هیچ مدل یا migration تغییر نکرده است. منطق قیمت، ثبت محصول، صف ارسال/بازنشستگی، تأخیر ۴۵ دقیقه و Worker تغییر نکرده‌اند. اعلان خصوصی غیرفعال باقی می‌ماند. پنل team و سایت عمومی از CSS جدید استفاده نمی‌کنند.

موجودی ویترین عکس وضعیت فعلی دفتر تولید است؛ تأیید زنده همگام‌بودن سایت و تلگرام نیست. به‌روزرسانی با بارگذاری صفحه انجام می‌شود.
ارزش فروش از قیمت فعلی ثبت‌شدهٔ محصولات محاسبه می‌شود؛ مدل مبلغ قطعی زمان فروش در این اصلاحیه ایجاد نشده است.
نمودار روند قدیمی در تحلیل‌ها و پروفایل ۳۱ روز پایانی را نشان می‌دهد و برچسب دارد؛ نمودار جزئیات شاخص تمام بازه را پوشش می‌دهد.
جدول‌ها بدون JavaScript قابل استفاده هستند؛ بعضی تبدیل‌های نمایشی عمومی با JavaScript فعال می‌شوند. نمودار جدید جدول دادهٔ جایگزین دارد.
طراحی وب با الگوهای موبایل و راهنمای Apple HIG همسو شده؛ برنامه بومی iOS یا ادعای تأیید Apple نیست.

## بررسی انجام‌شده
- ۶۱۸ تست Django: OK، یک مورد skipped.
- ۵۲ تست JavaScript موجود: پاس.
- بررسی مرورگر Chromium برای ۱۳ مسیر مدیریت با داده‌های نمونه در عرض‌های ۳۲۰، ۳۶۰، ۳۹۰، ۴۳۰، ۷۶۸، ۱۴۴۰ و حالت افقی.
- تعامل فیلتر، مرتب‌سازی سرور، بزرگنمایی عکس، برگشت، منو و انصراف از غیرفعال‌سازی حساب بررسی شد.
- صفحه جزئیات با ثبت‌کننده خالی، یادداشت شامل HTML، رکورد حذف‌شده، حساب فقط‌خواندنی و حساب فلوریست تست شد.
- Safari واقعی، VoiceOver و شبکه کند گوشی باید در بازبینی محلی کاربر بررسی شوند؛ نتیجه Chromium جایگزین آن‌ها نیست.

## اعمال محلی

```powershell
git apply --check .\zad-studio-manager-app-polish.patch
git apply .\zad-studio-manager-app-polish.patch
python manage.py check
python manage.py test main.tests.test_manager_app main.tests.test_studio_manager_overview main.tests.test_studio_ui main.tests.test_studio_team_management
git diff --check
python manage.py runserver 0.0.0.0:8000
```

CSS و JavaScript تازه فایل جدا دارند. پس از اعمال، صفحه را تازه‌سازی کنید.
این مرحله روی لوکال است. برای VPS ابتدا وضعیت Git و وجود پچ قبلی بررسی شود؛ اگر پچ قبلی روی VPS اعمال نشده، دو پچ باید به ترتیب اعمال شوند یا از تغییرات نهایی یک پچ تجمیعی ساخته شود. سپس collectstatic و restart سرویس وب لازم است. Worker و سرویس delivery نیازی به استقرار مجدد ندارند.
