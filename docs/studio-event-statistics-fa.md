# آمار بر اساس زمان رویداد

مبنا: نسخهٔ سفارشی‌های فروخته‌شدهٔ مستقر روی VPS با commit b433399 و کد معادل محلی.

- تعداد، ارزش و میانگین قیمت تولید بر اساس produced_at محاسبه می‌شوند.
- تعداد و مبلغ فروش و میانگین فاصلهٔ تولید تا فروش بر اساس sold_at محاسبه می‌شوند.
- تعداد کشیده‌شده‌ها بر اساس withdrawn_at محاسبه می‌شود.
- مرز روز، نیمه‌شب به وقت ایران است؛ ابتدای بازه شامل و ابتدای روز بعد از پایان بازه خارج است.
- تمام بازه‌های امروز، هفته، ماه، سه‌ماه و دلخواه این قاعده را دارند.
- محصولی که قبلاً تولید و در این بازه فروخته یا خارج شده است در جدول رویدادهای بازه نیز دیده می‌شود.
- آمار داشبورد، مقایسه با دورهٔ قبل، هر فلوریست، تحلیل نوع محصول، خلاصهٔ محصولات و نمودار روزانه یکسان‌اند.
- ترکیب تولید و موجودیِ تولیدهای بازه بر اساس تاریخ تولید باقی می‌مانند؛ موجودی کارت، شمارش تاریخی موجودی انبار در ابتدای آن روز نیست.
- نرخ فروش تولیدهای بازه برابر سهم محصولات فروخته‌شده از تولیدهای همان بازه است. فروش موجودی قدیمی این درصد را بالاتر از ۱۰۰ نمی‌برد.
- نمودار تولید و فروش، هر سری را در تاریخ خودش قرار می‌دهد؛ تعداد کشیده‌شدهٔ هر روز در جدول داده‌های نمودار قابل مشاهده و مرتب‌سازی است.
- رکوردهای حذف مدیریتی مانند قبل از آمار عملیاتی کنار گذاشته می‌شوند؛ دفتر حسابرسی آنها حفظ می‌شود.

هیچ داده، زمان فروش، وضعیت، رسانه، تنظیمات، مدل یا مهاجرتی تغییر نمی‌کند. مسیر ارسال و نگهداری سفارشی‌ها، آماده‌ارسال، تأخیر حذف ۴۵ دقیقه‌ای، Worker و اعلان خصوصی دست‌نخورده‌اند.

## بررسی محلی

```powershell
python manage.py check

git diff --check
```
