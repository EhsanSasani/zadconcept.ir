# نسخهٔ ۳ — مسیر کاربر و معیارهای پذیرش

وضعیت همهٔ آزمون‌های زیر: طراحی‌شده، اجرا نشده.
محیط اجرای این گفتگو موجود نیست. بررسی ایستای کد با اجرای تست یا آزمون کاربران واقعی معادل نیست.

## آزمون UI و regression
- عرض معادل ۳۲۰، موبایل معمول و دسکتاپ؛ متن بزرگ و zoom؛ تصاویر و عنوان‌های واقعی بلند.
- صفحه‌کلید موبایل، safe-area، نوار ثابت و فوکوس؛ target راحت و فاصلهٔ اقدامات متفاوت.
- RTL همراه شماره، کد سفارش، URL و قیمت؛ ترتیب نمایش و کپی درست.
- خطا و status با متن/نشانه و semantics؛ نه فقط رنگ و نه اعلام هر ثانیهٔ countdown.
- reduced motion، بارگذاری کند، شکست درخواست و دادهٔ خالی؛ مسیر اصلی بدون animation کار کند.
- back و refresh، drawer/menu/search، account/cart در هدر؛ رفتار فعلی کاتالوگ و lead حفظ شود.
- regressionهای موجود بر مبنای نهایی بررسی شوند: test_same_day_catalog، test_studio_projection_sync، test_sales_workspace، test_studio_publishing، test_account_management، test_panel و test_team_portal.
- اجرای کامل gates ریشهٔ AGENTS.md و برنامهٔ migration؛ این اسامی هدف اجرای آتی‌اند، گزارش PASS نیستند.

## پایان کار
هر مورد با Passed/Failed/Blocked/Not run، روش، محیط و مدرک واقعی ثبت شود. مطالعهٔ کاربران انسانی، در صورت اجرا، جدا از تست خودکار و نظر عامل هوش مصنوعی گزارش شود. تا تعیین baseline و فراهم‌شدن محیط، release و تست عملی مسدودند.
