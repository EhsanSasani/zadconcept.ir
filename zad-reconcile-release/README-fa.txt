بستهٔ نهایی تطبیق Studio — ۳ اکتبر ۲۰۲۶

این بسته شامل دو پچ است که از دو مبنای متفاوت به کد یکسان می‌رسند:
- zad-studio-reconcile-5821425.patch: مخصوص local با مبنای 5821425
- zad-studio-reconcile-vps-86e058b.patch: مخصوص VPS با مبنای 86e058b

برای ادامه از پچ‌های همین بسته استفاده کنید. هر پچ فقط برای مبنای خودش است.
اعمال هر دو پچ روی یک محیط درست نیست. پیش از اعمال، git status و git log و
سپس git apply --check بررسی می‌شوند؛ اگر خطا بود، اعمال ادامه پیدا نمی‌کند.

نتیجه: حفظ اصلاحات ایمنی پچ بزرگ، مهلت ۴۵ دقیقه‌ای حذف تلگرام، انتخاب اجباری
نوع تولید، نمایش جداکنندهٔ قیمت با حفظ محل نشانگر و خاموش‌بودن اعلان خصوصی.
صف‌های خصوصی قبلی حفظ می‌شوند و در حالت خاموش پردازش یا بازیابی نمی‌شوند.
کد اجرایی Worker و فایل‌های مدل و migration تغییر نکرده‌اند.

در دو کپی مستقل، اعمال هر پچ و git diff --check موفق بود. محتوای ۴۹۹ فایل
کد، تنظیم نمونه، مستندات و تست‌ها در نتیجهٔ دو پچ مقایسه و یکسان تأیید شد.
مجموعهٔ ۵۸۸ تست Django (یک مورد skipped)، ۵۲ تست JavaScript و بررسی Chromium
در اندازه‌های موبایل/تبلت/دسکتاپ موفق بود. check و نبود تغییر migration روی
کپی ساخته‌شده از آرشیو VPS نیز بررسی شد. این شواهد، ارسال زنده روی VPS نیست.

قدم بعد: بررسی و اعمال local، تست، commit و push. سپس پشتیبان تازهٔ VPS،
بررسی سازگاری پچ سرور، اعمال، collectstatic و بارگذاری هر دو سرویس وب و
پردازشگر در زمان کوتاه هماهنگ‌شده با تیم. نتیجهٔ اعلان خصوصی باید disabled
باشد. نمونهٔ آزمایشی یا دیتابیس local به سرور عملیاتی منتقل نمی‌شود.

راهنمای کامل در فایل ROLLOUT-fa.md این بسته و پس از اعمال در
 docs/studio-reconciliation-rollout-fa.md قرار دارد.
verification.json نتیجهٔ بررسی و source-sha256.json اثرانگشت منابع مشترک را
نگه می‌دارند. هیچ فایل .env واقعی، دیتابیس یا رسانهٔ آپلودشده در این بسته نیست.
