TELEGRAM CAPTION FORMAT

ورودی قبلی تلگرام

فلوریست‌ها در پنل تیم عکس، قیمت و فاکتور را وارد می‌کنند؛ کپشن خروجی خودکار ساخته می‌شود. این راهنما فقط برای ادامهٔ استفاده از ورودی قبلی تلگرام است.

برای محصول سفارشی، یک عکس تکی و این چهار فیلد را ارسال کنید:

florist: mz
type: box
factor: 1234
price: 2400000

برای گروه ارسال روز همین چهار فیلد را بنویسید و برچسب قیمت را «قیمت: 2400000» قرار دهید تا با پارسر فعلی قیمت نیز سازگار باشد.

قیمت بر حسب تومان است. کد فلوریست باید قبلاً در داشبورد تعریف و فعال شده باشد. شماره فاکتور تکراری پذیرفته نمی‌شود.
