# CSS architecture

The stylesheet order is a public contract. `base.html` loads foundations first,
then shared layout/components, page-owned styles, the dynamic hero configuration
generated by Django, and finally the global accessibility policy.

## Ownership

| File | Owns |
| --- | --- |
| `tokens.css` | Global design tokens and compatibility aliases; the only global `:root` |
| `base.css` | Local fonts, reset, and element defaults |
| `utilities.css` | Small single-purpose helpers such as `.sr-only` |
| `layout.css` | Containers, landmarks, breadcrumbs, and shared page geometry |
| `navbar.css`, `footer.css` | Global chrome |
| `hero.css`, `hero-config.css` | Shared hero structure and CMS-controlled hero behavior |
| `components.css` | Reusable buttons, forms, cards, rails, and shared sections |
| `page.css` | Shared legacy page families that have not yet earned a dedicated file |
| `responsive.css` | Existing cross-page compatibility overrides; new responsive rules stay with their owner |
| `accessibility.css` | Last-loaded focus, skip-link, hidden-state, and reduced-motion safeguards |
| Page files | One page/domain only (`home.css`, `flowers-landing.css`, `policy.css`, etc.) |

## Rules

1. Add a token before repeating a new brand color, focus ring, motion value, or z-index.
2. Scope page rules under that page's body class; do not patch another page from a page stylesheet.
3. Keep responsive rules next to the component or page that owns them. `responsive.css` is compatibility-only.
4. Do not create `final`, `polish`, `hotfix`, or versioned patch stylesheets. Move the rule to its owner.
5. Do not use presentational classes as JavaScript hooks; use `data-*` attributes.
6. Avoid `!important`. It is reserved for accessibility utilities, CMS-authored hero variables, and documented legacy compatibility.
7. Run `npm run lint:css` and the Django frontend-contract tests before committing CSS.

The canonical product card is `.flowers-product-card`. The retired
`.product-card` and `.featured-product-card` variants must not return.
